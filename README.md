# Детектор кибербуллинга — демо

Демо гибридной модели **CustomBERTCNNAttentionModel** (BERT + Multihead Self-Attention + CNN) для автоматического обнаружения кибербуллинга в текстах социальных сетей. Модель разработана в рамках научного проекта ИРН AP23488900 «Автоматическое обнаружение кибербуллинга среди молодежи в социальных сетях с использованием искусственного интеллекта».

- **Онлайн-демо:** https://daniyar3348.github.io/cyberbullying-demo/
- **Сервер с моделью:** Hugging Face Spaces (ссылка появится после развертывания)

> Модель работает в демо-режиме: обученные веса пока не загружены, выходной слой инициализирован случайно, поэтому вероятность кибербуллинга близка к 50 % и смысла не несет. Архитектура и предобработка текста — настоящие.

## Устройство

| Путь | Назначение |
|---|---|
| `index.html` | Интерфейс, публикуется через GitHub Pages. Адрес сервера задается в `<meta name="api-base">` |
| `space/` | Сервер на FastAPI с моделью, разворачивается на Hugging Face Spaces (Docker) |
| `space/model_cyberbullying.py` | Архитектура модели: BERT → Multihead Self-Attention → 2 × Conv1D → Max Pooling → Linear |
| `space/preprocessing.py` | Очистка текста и токенизация |

Страница отдает текст серверу, сервер возвращает вероятность кибербуллинга, текст после предобработки и число токенов.

## API

- `GET /api/status` — состояние модели (загружается, готова, обучена ли)
- `POST /api/predict` с телом `{"text": "..."}` — результат классификации

## Локальный запуск

```bash
cd space
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
MODELS_DIR=. uvicorn app:app --port 7860
```

Интерфейс откроется на http://localhost:7860. При первом запуске скачивается энкодер `bert-base-uncased` (около 440 МБ).

## Подключение обученных весов

Сохраните веса через `torch.save(model.state_dict(), "checkpoints/model.pt")` и положите их в `space/checkpoints/`. Для многоклассовой модели рядом нужен `classes.json` со списком классов в порядке выходов модели. После перезапуска сервер перейдет из демо-режима в рабочий.
